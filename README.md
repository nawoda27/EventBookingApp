# 🎟️ EventBookingApp

### Android Event Booking Application

EventBookingApp is an Android application designed to provide a simple platform for users to explore and book events.

The application uses **Java and Firebase** to provide user authentication and cloud-based application functionality.

---

## ⭐ Project Overview

EventBookingApp is developed as an Android application that demonstrates the implementation of an event booking system.

The project focuses on user registration, login, event-related functionality, and Firebase integration.

---

## 🔑 Key Features

- 🔐 User Registration
- 🔑 User Login
- 👤 User Account Management
- 🏠 Home Screen
- 🎟️ Event Booking Functionality
- 🛡️ Admin Functionality
- ☁️ Firebase Integration
- 📱 Android Mobile Application

---

## 👥 User Roles

### 👤 User

- Create an account
- Login to the application
- Access the home screen
- Browse available event information
- Book events

### 🛡️ Administrator

- Access admin functionality
- Manage event-related information
- Monitor application activities
